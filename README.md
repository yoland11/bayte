# بيتي — متابع حسابات بناء المنزل

تطبيق عربي باتجاه من اليمين إلى اليسار لمتابعة قبض وصرف بناء منزل واحد، مع حفظ المرفقات والتقارير.

## التشغيل محلياً

```sh
npm install
npm run dev
```

## البيانات والتقارير

تُحفظ العمليات والتصنيفات ومراحل البناء وصور الإيصالات في هذا المتصفح باستخدام قاعدة بيانات محلية. تبقى المبالغ أرقاماً، وتُحفظ الصور منفصلة ومرتبطة بالعمليات. لا يستخدم التطبيق خادماً أو مزامنة سحابية. يمكن تصدير تقرير مفلتر بصيغة PDF أو جدول بيانات Excel يتضمن صفحات منفصلة للملخص والعمليات والتصنيفات والمراحل.

## التحقق من المشروع

```sh
npm test
npm run build
```
